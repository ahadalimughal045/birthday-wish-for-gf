# Happy Birthday Surprise ❤️🎂

An interactive, romantic birthday celebration website featuring:
- 🎂 **12:00 AM Cake Cutting**: Interactive 3D birthday cake with candle-blowing, slicing animation, and confetti bursts.
- 🧸 **Bubu & Dudu Characters**: Animated interactive avatars with cute reactions.
- 📸 **Polaroid Love Chapters**: Beautiful memories with hover effects and fullscreen lightbox zoom.
- 💌 **3D Wax-Sealed Love Letter**: Interactive opening animation.
- 🎵 **Romantic Audio Player**: Built-in background music and web audio synthesizer.
- 📱 **Fully Responsive**: Optimized for all mobile, tablet, and desktop devices.
